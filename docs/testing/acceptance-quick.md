# 快速验收（约 15 分钟）

这份清单只挑**真正影响日常使用、而且自动化看不到**的东西。完整清单在
`electron-windows-manual-checklist.md`（12 组 87 项），那是给"要发布给别人用"准备的；
这里是你自己用的工具，走完这 12 条就够了。

## 怎么开始

```powershell
npm run acceptance
```

它会打印一条 `npm start -- --user-data-dir="..."` 命令。**用那条命令启动**——
数据来自临时目录，你真实清单（`%APPDATA%\dotodo`）一个字都不会动。

看完请从**托盘菜单**选「退出」。窗口的关闭按钮只是隐藏，不会退出应用。

### 它现在真的贴在桌面上

窗口不再浮在桌面**之上**，而是桌面的一部分：和桌面图标同级，只会出现在桌面上。
所以**别的窗口开着的时候你看不到它** —— 按 `Win+D` 露出桌面就能看到。

两个由此而来的习惯：

- **打字之前先点它一下。** 桌面本身永远不会被"激活"，键盘不会自己落到它身上；
  点的那一下由主进程把焦点补回来。不点直接敲键盘是没有反应的。
- 它**不会被"点起来"盖住你正在做的事**，这是有意的，不是失灵。

## 逐条看

每条都写了「做什么」和「应该看到什么」。**看到的不对就记下编号**，不用当场分析原因。

### 1. 面板外观

**做什么**：把窗口拖到一张**浅色**壁纸上方。

**应该看到**：面板是中性灰的半透明玻璃，不是蓝色调。四条边有细描边（深色壁纸上也看得出边界）。
圆角。文字全部清楚——尤其是日期、进度计数这类灰色小字。
面板**外圈没有灰框、也没有投影**——看到一圈淡淡的灰边就是回归了。

> 透明度是**固定的**，没有滑杆可调。这是故意的：可读性不该是能被调坏的设置项。

### 2. 拖动与缩放记忆

**做什么**：拖标题栏移动窗口，拖边框改大小，然后退出、重新启动。

**应该看到**：能移动、能缩放；重启后位置和尺寸和你离开时一样。

### 3. 添加与勾选

**做什么**：先点一下面板（让键盘焦点落上来），在输入框打字回车；再点某一行左边的圆圈。

**应该看到**：新任务出现在**列表底部**；勾选后圆圈变成绿色对勾、文字划掉、右上角的进度计数变化。
已完成的任务**留在原位**，不会自动沉到底部。

### 4. 编辑、删除、撤销

**做什么**：
1. 双击某条任务的文字，改几个字，按 Enter；
2. 再双击一次，改点东西，按 Esc；
3. 选中一行按 Delete，然后点右下角弹出的「撤销」。

**应该看到**：Enter 提交修改；Esc **放弃**修改（原文不变）；Delete 后出现一条 6 秒撤销条，
点「撤销」任务回到**原来的位置**。撤销条自己会消失。

### 5. 历史页是只读的

**做什么**：点底部「历史」，双击里面任意一条任务的文字。

**应该看到**：昨天那组任务在，带完成统计。双击**没有任何反应**——历史是只读的。

### 6. 延续到今天

**做什么**：在历史页找到「给客户回邮件」（未完成），点它右边的「延续到今天」；
然后切回「今天」。

**应该看到**：它出现在今天的列表底部，是未完成的。**再切回历史**，那行的按钮消失了，
改成显示「已延续到」——同一件事**终身只能延续一次**。

### 7. 托盘图标与菜单

**做什么**：看屏幕右下角通知区域；右键托盘图标。

**应该看到**：图标清晰不是空白方块。菜单里有：显示窗口、隐藏窗口、关闭时隐藏、
开机启动、退出。点「隐藏窗口」窗口消失，点「显示窗口」回来。

### 8. 关闭按钮只隐藏

**做什么**：点窗口右上角的关闭按钮，然后从托盘把窗口叫回来。

**应该看到**：窗口消失但**应用没退出**（托盘图标还在），能从托盘叫回来。
只有在托盘菜单里选「退出」才真的退出。

### 9. 全局快捷键

**做什么**：按 `Ctrl+Shift+Space`，再按一次。

**应该看到**：整个面板在桌面上出现／消失。快捷键现在管的是"它要不要待在桌面上"，
**不会**把它抬到别的窗口上面——那是桌面部件的本分。

> 这个键可能被输入法或截图工具占用。**占用了不会弹任何提示**，只是不生效——那时候用托盘就行。
> 这是故意的：用户处理不了的事不该占用界面提示位。

### 10. 设置面板本身

**应该看到**：面板能开能关，关闭按钮在面板右上角。里面有关闭时隐藏到托盘、
开机启动、导入、导出、打开数据目录。**没有背景透明度，也没有窗口层级。**

### 11. 拖拽换位

**做什么**：加三条任务（比如 `A`、`B`、`C`），按住**第 1 条**拖到**第 3 条**上，松开。

**应该看到**：

- 按住时那一行**明显变淡**，还带一圈虚线框；鼠标移到别处不动时，左边会露出拖动把手。
- 拖动过程中有一条**黑线**标出会插到哪儿：往**下**拖画在目标行的**下边**，往**上**拖画在**上边**。
- 松手后 **`A` 真的跑到第 3 位**（`B`、`C` 各上移一位），而不是只往下挪了一格。

> 这条以前是错的：往第 3 行拖，结果它跑到了第 2 行。现在有自动化断言盯着结果，但手感只能你来看。

### 12. 数据真的落到磁盘

**做什么**：加一条任务，从托盘退出，再用同一条命令启动。

**应该看到**：那条任务还在。今天是空的也不会丢——新的一天从空的开始，昨天整天进历史。
