# DoTodo Electron Exercises

This directory contains the standalone exercise set for the DoTodo Electron course.

- `README.md` explains the workflow and exercise index.
- Each `NN-*/` directory contains the problem statement, a blank `starter.js`, and its grading test.
- Personal answers are intentionally not committed. Keep your working answers outside this repository.
- These exercises are independent of the application test command; run them from this directory.

The application itself is documented in the repository root [`README.md`](../README.md).
